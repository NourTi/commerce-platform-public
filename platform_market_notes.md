# Independent commerce platform — market notes

## Established platform baseline

EverShop is a TypeScript-first ecommerce platform with GraphQL, React, SSR, an admin panel, a modular architecture, themes, and extension mechanisms. It is a credible integrated reference point, but its core does not visibly package the company-account and B2B purchasing workflows identified in the earlier evidence log.

Saleor positions itself as an open-source, API-first, composable commerce platform with an extensible administration dashboard. Its published capabilities include GraphQL, commerce primitives such as PIM and OMS, dashboard UI extensions, webhooks, configuration-as-code tooling, and OpenTelemetry observability. This means an independent project cannot win merely by claiming to be headless, GraphQL-first, extensible, or observable.

Source: https://saleor.io/

Vendure positions its open-source core as a TypeScript, NestJS, and GraphQL commerce framework. Its extension model spans plugins, strategy replacement, custom fields, custom entities, typed events, background jobs, and extensible Admin and Shop GraphQL APIs. This establishes a second strong baseline: developer extensibility must be deliberate and typed, not a collection of undocumented override points.

Source: https://vendure.io/core

## Directional implication

The independent platform needs to avoid a generic “better framework” claim. A viable wedge must combine a differentiated commercial model with developer experience that reduces time-to-market and upgrade risk. It should be opinionated where existing platforms make every project assemble primitives, while retaining clear extension boundaries where the business is truly specific.
